# МиСКЗИ — решатель задач

2026/2027 · Методы и средства криптографической защиты информации (очная, Зюляркина Н. Д.)

Сайт: https://university-assignments.github.io/cryptography/

Считает задания контрольных автоматически и расписывает решение по шагам — как в тетради: матрицы, числовые последовательности, уравнения, таблицы перебора. Работает целиком в браузере, сервера нет.

## Что внутри

- **Контрольная №1 — классические шифры**: Хилл (аффинный, `A⁻¹ mod m` через присоединённую матрицу), магический квадрат (достройка ключа парными уравнениями и перебор только по неизвестным клеткам, все решения; маршрутная перестановка — все способы обхода), Виженер с обратной связью (автоключ по открытому тексту или шифртексту), Цезарь (перебор ключей), Плейфер (5×5 без J или 4×8 для русского без Ё).
- 6 вариантов с условиями с листа заданий + «свои данные» с пустыми полями; ответы из тетрадей всех шести вариантов — тест-кейсы.
- Фото условия и тетради по каждому варианту (`public/photos/work-1/vN`), лайтбокс на PhotoSwipe.
- Имя пользователя (localStorage) → `cyrb53` → выбор решения там, где их несколько (задание 2: какой из квадратов используется для шифрования).
- Все поля задания лежат в query-параметрах: ссылка воспроизводит решение; параметр появляется в URL только когда значение отличается от условия варианта.

## Стек

Vue 3 + Vite + TypeScript, vue-router, Tailwind CSS v4, PhotoSwipe. Линт: oxlint + ESLint (`@stylistic`, `eslint-plugin-vue`), типы — `vue-tsc`, тесты — Vitest. Деплой — GitHub Actions собирает `dist/` и публикует в ветку `gh-pages` (Pages: Deploy from a branch → `gh-pages` / root); `404.html` = копия `index.html` для history-роутинга, `.nojekyll` отключает Jekyll.

```sh
pnpm install
pnpm dev             # http://localhost:5173/cryptography/
pnpm test            # vitest — ответы из тетради как тест-кейсы
pnpm lint            # oxlint + eslint --fix
pnpm build           # type-check + vite build → dist/
```

## Аналитика

В `index.html` только Google Tag Manager — контейнер `GTM-PX9V8NJW` («криптография», аккаунт «университет»); GA4 (`G-VF2MEGJMF1`) подключается внутри него:

- **GA4** — тег Google на `Initialization - All Pages`, первый `page_view` при загрузке.
- **GA4 - page_view (SPA)** — событие `page_view` на триггер «Изменение в истории» с условием `History Source` ~ `^(pushState|popstate)$`. `replaceState` не считается: его делает `useQueryParam` на каждую правку поля задания.
- В потоке GA4 «Изменения состояния страницы в истории браузера» выключено, чтобы просмотры не дублировались.
- **Имя пользователя** — переменная «JS - Имя пользователя» читает `localStorage['cryptography:name']`, оно уходит свойством пользователя `user_name` со всеми событиями GA4. Тег «JS - Ввод имени» ловит отправку формы с полем `#name` → событие `login`. Ключ `cryptography:name` и `id="name"` — контракт с контейнером: переименуешь — поправь GTM.
- **Время на странице** — тег «JS - Уход со страницы» (пользовательский HTML) при уходе шлёт `page_leave`: `time_on_page_sec` — сколько секунд страница была видна (свёрнутая вкладка не считается), `leave_type` — `navigate` (переход по сайту) / `hidden` (свернул, переключил или закрыл вкладку) / `pagehide` (запасной), `page_location` — страница, с которой ушли. Вернулся на вкладку — отсчёт заново, сумма `time_on_page_sec` = всё видимое время.
- В GA4 зарегистрированы: параметр пользователя «Имя пользователя» (`user_name`), параметр события «Причина ухода со страницы» (`leave_type`), показатель «Время на странице» (`time_on_page_sec`, сек).

## Статистика: у кого какой вариант

- Личная ссылка: `…/cryptography/?id=<md5>`, где id — md5 от имени (без пробелов по краям, в нижнем регистре). id сохраняется в браузере (`localStorage['cryptography:id']`) и сразу убирается из адреса, чтобы не уйти дальше вместе с пересланной ссылкой.
- Имя спрашивается как и раньше.
- Сайт отправляет в Google Таблицу через Apps Script (`stats/apps-script.gs`, `src/config.ts → STATS_URL`):
  - **Просмотры** — сколько секунд человек провёл на странице варианта или задания;
  - **Смена ID** — первый заход по личной ссылке и переход по чужой (старый → новый);
  - **Смена имени** — какие имена вводились под каждым ID (старое → новое);
  - **Сводка** — ID × вариант → суммарное время: самое большое число в строке и есть его вариант.
- Пока `STATS_URL` пустой, ничего не отправляется.
